# Security

Countersign guards money moves made by AI agents, so security reports matter. Please report vulnerabilities privately through GitHub security advisories for this repository, not as public issues.

In scope: bypassing a hold or a rule, moving money without an approved intent, replaying or forging agent identity, reading another agent's data, leaking keys or tokens, and prompt injection that changes a decision.

Countersign talks only to the PayPal **Sandbox** (test money). It is a hackathon build and is not reviewed for production payments.
